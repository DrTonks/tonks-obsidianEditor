# Obsidian 插件截图说明

将下列四张真实 Obsidian 截图保存为 PNG 放在本目录。项目 README 已预留引用；这些文件当前是待补素材，不表示交互已经验收。

## 拍摄准备

1. 按 [安装步骤](../../README.md#安装到博客) 构建博客适配器、安装并启用插件，Obsidian 仓库选择博客 `src/content`。
2. 使用一篇用于演示的草稿，设置 `draft: true`，准备短标题、二级标题、几段文字和引用块。不要为拍摄修改正式文章。
3. 推荐在同一篇草稿中插入一个博客引用格式和一个文章卡片，让预览能展示博客专属样式。需要比较亮暗主题时使用同一内容与滚动位置。

## 文件与画面

| 文件名 | 操作 | 画面重点 |
| --- | --- | --- |
| `blog-preview-light.png` | 打开演示草稿，点击左侧书本图标或右键“博客预览”，选择亮蓝或亮黄 | 作为 README 主图，保留 Obsidian 界面、预览工具栏及主题选择器；正文包含标题、引用和文章卡片，避免只有空白或长篇纯文字。 |
| `format-context-menu.png` | 返回编辑，选中一小段文字，在正文区域右键；若格式入口有子菜单，将其展开 | 同时看到选区、插件格式菜单与可选项；菜单不能被屏幕边缘截断。此图拍摄后可取消操作，不必插入。 |
| `format-dialog.png` | 从菜单选择需要填写参数的格式，例如带来源字段的引用 | 完整展示真实参数表单、字段标签与操作按钮；填写简短的演示值，保留部分编辑器背景。以当前配置实际提供的表单为准。 |
| `blog-preview-dark.png` | 对同一篇草稿再次打开博客预览，切换暗蓝或暗黄 | 保留主题选择器，与亮色图使用同样窗口大小、内容及滚动位置，便于对比。 |

建议窗口约 1440 × 900 或更大，保留清晰中文；裁掉桌面、无关窗口及私人文件列表。弹窗与菜单图可以聚焦局部，但要让读者看出它们位于 Obsidian 编辑器中。

只拍摄实际可用功能，不将 Obsidian 自带阅读视图当作插件预览。图片保存后沿用文件名即可，不需要调整 README。拍摄完成后可在此补充日期、Obsidian 版本与插件版本；截图本身不替代插入、撤销及预览刷新验收。
